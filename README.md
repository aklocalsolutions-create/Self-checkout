# AirRegister Self-Checkout (test build)

Version 1.2.3.1-selfcheckout.test.1. This is a test build. It hasn't been tried on Windows yet. Download the installer from the Releases page.

sha256: a91e0ea21e57006500af00908d46fdc2f7bb6306ea18940ad802ca9fb508df64

## Install
1. Download the .exe from Releases and double-click it. If Windows SmartScreen warns, choose More info, then Run anyway.
2. Sign in to AirRegister, open Settings, go to the Self-checkout tab and tick "Self-checkout available".
3. Open the manager menu, tap "Self-checkout mode" and sign in with your normal register login.
4. To leave it, tap the hidden staff corner, sign in, then choose Exit self-checkout.

This installs over the regular AirRegister and keeps its settings. To go back, install the regular release. Auto-update is off in this build.
